# AURA Voice Assistant

AURA is a voice-controlled Android phone assistant built using Python, Flask, JavaScript, Web Speech API, and ADB.

## Features
- Voice command recognition
- Web-based assistant interface
- Android phone control through ADB

## Requirements
- Python 3
- Flask
- Android Debug Bridge (ADB)

## Setup
Install dependencies using:

`pip install -r requirements.txt`

Configure ADB and connect your Android phone before running the assistant.
